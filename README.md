 Abstract
Tourism is a dynamic industry influenced by seasonal variations, socio‑economic factors, and global events.
Traditional forecasting methods often fail to capture these complexities. 
This project applies descriptive data mining techniques (clustering, association rules, trend analysis) to uncover historical travel patterns and
predictive models (regression, decision trees, neural networks) to forecast future demand. The integration of these approaches provides actionable
insights for tourism boards, hotels, and travel agencies, enabling better resource allocation, marketing optimization, and improved customer experience.
Setup & Execution Instructions
Clone or download the repository.
Install dependencies:
bash
pip install -r requirements.txt
Prepare datasets: Place tourism datasets (visitor arrivals, hotel occupancy, seasonal demand) in the data/ folder.
Run descriptive analysis:
bash
python src/descriptive_analysis.py (http://analysis.py/)
Run predictive models:
bash
python src/predictive_models.py (http://models.py/)
View results: Outputs and visualizations will be stored in the results/ folder.
